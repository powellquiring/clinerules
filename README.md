# Clinerules

This repository contains custom rules and guidelines for the Cline AI coding assistant. It helps enforce best practices, secure file operations, and safe execution within the environment.

## Overview

The repository consists of several rules documents:

* **01-cline-behavior.md**: General file operation guidelines, terminal execution rules, and read-only constraints for Git, Terraform, and Auth0.
* **02-superpowers.md**: Workflow for handling superpower specs and plans.
* **03-terraform.md**: Strict read-only guardrails for Terraform to prevent unwanted infrastructure or state modifications.

These rules ensure that the AI assistant operates safely and reliably within the constraints of the project.
